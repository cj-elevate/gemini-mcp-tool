# API

This MCP server uses the `@google/genai` SDK to communicate with Google's Gemini API.

## Tools

See [Tool Reference](/usage/commands) for the complete list of available MCP tools and their parameters.

## SDK

The server uses `@google/genai` (Google's official Generative AI SDK for Node.js). Authentication is via `GEMINI_API_KEY` environment variable.
